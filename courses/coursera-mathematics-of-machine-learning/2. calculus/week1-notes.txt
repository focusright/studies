QUIZ
Unleashing the toolbox


1.
f(x) = x³⸍² + πx² + √7, what is f'(2)?
f'(x) = 3/2 x¹⸍² + 2πx
f'(2) = 3/2 √2 + 2π2 = √2(3/2) + 4π


2.
f(x) = x³ cos(x) eˣ
Use product rule applied twice
let A(x) = x³, B(x) = cos(x) eˣ
f'(x) = A(x)B'(x) + A'(x)B(x)
let C(x) = cos(x), D(x) = eˣ
B'(x) = C(x)D'(x) + C'(x)D(x)
put it all together
f'(x) = A(x)B'(x) + A'(x)B(x)
      = A(x)[C(x)D'(x) + C'(x)D(x)] + A'(x)B(x)
      = x³[cos(x)eˣ - sin(x)eˣ] + 3x²(cos(x)eˣ)
      = x³eˣcos(x) - x³eˣsin(x) + 3x²cos(x)eˣ
      = - eˣx³sin(x) + eˣx³cos(x)  + 3eˣx²cos(x)


3.
f(x) = e^(x + 1)²
let f(x) = f(g(x)) where f(x) = eˣ, g(x) = (x + 1)²
g(x) = x² + 2x + 1
f'(x) = f'(g(x)) g'(x) = df/dg * dg/dx
      = eᵍ * (2x + 2)
      = e^(x + 1)² * 2(x + 1)


4.
f(x) = x² cos(x³)
product rule and chain rule together
f'(x) = A(x)B'(x) + A'(x)B(x)
let A(x) = x², B(x) = cos(x³)
let C(u) = cos(u), u(x) = x³
f'(x) = x²B'(x) + 2x cos(x³)
B'(x) = dC/du * du/dx
      = -sin(u) * 3x²
      = -sin(x³) * 3x² = -3x²sin(x³)
put it together
f'(x) = x²(-3x²sin(x³)) + 2x cos(x³)
      = -3x⁴sin(x³) + 2x cos(x³)
      = 2x cos(x³) - 3x⁴sin(x³)


5.
f(x) = sin(x) eᶜᵒˢ⁽ˣ⁾, what is f'(π)
product rule and chain rule together
f'(x) = A(x)B'(x) + A'(x)B(x)
let A(x) = sin(x), B(x) = eᶜᵒˢ⁽ˣ⁾
let C(u) = eᵘ, u(x) = cos(x)
f'(x) = sin(x) B'(x) + cos(x) eᶜᵒˢ⁽ˣ⁾
B'(x) = dC/du * du/dx
      = eᵘ * -sin(x)
      = -eᶜᵒˢ⁽ˣ⁾ sin(x)
put it together
f'(x) = sin(x) [-eᶜᵒˢ⁽ˣ⁾ sin(x)] + cos(x) eᶜᵒˢ⁽ˣ⁾
      = -eᶜᵒˢ⁽ˣ⁾sin(x)² + eᶜᵒˢ⁽ˣ⁾cos(x)
f'(π) = -eᶜᵒˢ⁽π⁾sin(π)² + eᶜᵒˢ⁽π⁾cos(π)     NOTE: cos(π) = -1, sin(π) = 0
      = 0 + -e⁻¹
      = -1/e
