NEWTON–RAPHSON METHOD
https://en.wikipedia.org/wiki/Newton%27s_method

The equation of the tangent line to the curve y = f(x) at x = xₙ is

y = f'(xₙ)(x - xₙ) + f(xₙ)

The x-intercept of this line (the value of x which makes y = 0) is then used as 
the next approximation to the root, xn + 1. Setting y to zero and x to xn + 1 gives

0 = f'(xₙ)(xₙ₊₁ - xₙ) + f(xₙ)

solving for xₙ₊₁ gives

            f(xₙ)
xₙ₊₁ = xₙ - -------
            f'(xₙ)

*Steps : 0 = f'(xₙ)(xₙ₊₁ - xₙ) + f(xₙ)
         -f'(xₙ)(xₙ₊₁ - xₙ) = f(xₙ)
         -(xₙ₊₁ - xₙ) = f(xₙ)/f'(xₙ)
         -xₙ₊₁ + xₙ = f(xₙ)/f'(xₙ)
         xₙ₊₁ - xₙ = -f(xₙ)/f'(xₙ)
         xₙ₊₁ ₙ = -f(xₙ)/f'(xₙ) + xₙ
         xₙ₊₁ ₙ = xₙ - f(xₙ)/f'(xₙ)
