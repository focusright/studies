PRACTICE QUIZ
Practicing partial differentiation

1.
f(x, y) = πx³ + xy² + my⁴, m is a constant, what are ∂f/∂x and ∂f/∂y?
∂f/∂x = 3πx² + y²
∂f/∂y = 2xy + 4my³


2.
f(x, y) = x²y + y²z + z²x, what are ∂f/∂x, ∂f/∂y, and ∂f/∂z?
∂f/∂x = 2xy + z²
∂f/∂y = x² + 2yz
∂f/∂z = y² + 2xz


3.
f(x, y, z) = e²ˣsin(y)z² + cos(z)eˣeʸ, what are ∂f/∂x, ∂f/∂y, and ∂f/∂z?
∂f/∂x = 2e²ˣsin(y)z² + cos(z)eˣeʸ
∂f/∂y = e²ˣcos(y)z² + cos(z)eˣeʸ
∂f/∂z = 2e²ˣsin(y)z - sin(z)eˣeʸ


4.
Recall the formula for the total derivative, that is, for 
f(x,y), x=x(t) and y = y(t), one can calculate df/dt = ∂f/∂x * dx/dt + ∂f/∂y * dy/dt

Given that f(x,y) = πx²y, x(t) = t² + 1, y(t) = t² - 1
calculate the total derivative df/dt

∂f/∂x = 2πxy
dx/dt = 2t
∂f/∂y = πx²
dy/dt = 2t

df/dt = 2πxy * 2t + πx² * 2t
      = 2π(t² + 1)(t² - 1)2t + π(t² + 1)²2t
      = 4πt(t² + 1)(t² - 1) + 2πt(t² + 1)²


5.
Recall the formula for the total derivative, that is, for 
f(x,y,z), x = x(t), y = y(t) and z = z(t), one can calculate
df/dt = ∂f/∂x * dx/dt + ∂f/∂y * dy/dt + ∂f/∂z * dz/dt

Given that f(x,y,z) = cos(x)sin(y)e²ᶻ, x(t) = t + 1, y(t) = t - 1, z(t) = t²
calculate the total derivative df/dt

∂f/∂x = -sin(x)sin(y)e²ᶻ
dx/dt = 1
∂f/∂y = cos(x)cos(y)e²ᶻ
dy/dt = 1
∂f/∂z = cos(x)sin(y)2e²ᶻ
dz/dt = 2t

df/dt = -sin(x)sin(y)e²ᶻ * 1 + cos(x)cos(y)e²ᶻ * 1 + cos(x)sin(y)2ze²ᶻ * 2t
      = -sin(x)sin(y)e²ᶻ + cos(x)cos(y)e²ᶻ + cos(x)sin(y)2e²ᶻ * 2t
      = -sin(t+1)sin(t-1)e²ᵗ^² + cos(t+1)cos(t-1)e²ᵗ^² + cos(t+1)sin(t-1)2e²ᵗ^² * 2t
      = e²ᵗ^²[-sin(t+1)sin(t-1) + cos(t+1)cos(t-1) + cos(t+1)sin(t-1)4t]
      = [-sin(t+1)sin(t-1) + cos(t+1)cos(t-1) + 4t cos(t+1)sin(t-1)]e²ᵗ^²







PRACTICE QUIZ
Calculating the Jacobian


1.
For f(x, y) = x²y + ¾xy + 10, calculate the Jacobian row vector J.
J = [∂f/∂x, ∂f/∂y]
∂f/∂x = 2xy + ¾y
∂f/∂y = x² + ¾x
J = [2xy + ¾y, x² + ¾x]


2.
f(x, y) = eˣcos(y) + xe³ʸ - 2
∂f/∂x = eˣcos(y) + e³ʸ
∂f/∂y = -eˣsin(y) + 3xe³ʸ
J = [eˣcos(y) + e³ʸ, -eˣsin(y) + 3xe³ʸ]


3.
f(x, y, z) = eˣcos(y) + x²y²z²
J = [∂f/∂x, ∂f/∂y, ∂f/∂z]
∂f/∂x = eˣcos(y) + 2xy²z²
∂f/∂y = -eˣsin(y) + 2x²yz²
∂f/∂z = 2x²y²z
J = [eˣcos(y) + 2xy²z², -eˣsin(y) + 2x²yz², 2x²y²z]


4.
f(x, y, z) = x² + 3eʸeᶻ + cos(x)sin(z)
calculate the the Jacobian row vector and evaluate at the point (0, 0, 0).
∂f/∂x = 2x
∂f/∂y = 3eʸeᶻ
∂f/∂z = 3eʸeᶻ + cos(x)cos(z)
J = [2x, 3eʸeᶻ,3eʸeᶻ + cos(x)cos(z)]
J(0, 0, 0) = [0, 3, 3 + 1] = [0, 3, 4]


5.
f(x, y, z) = xeʸcos(z) + 5x²sin(y)eᶻ
calculate the the Jacobian row vector and evaluate at the point (0, 0, 0).
∂f/∂x = eʸcos(z) + 10x sin(y)eᶻ
∂f/∂y = xeʸcos(z) + 5x²cos(y)eᶻ
∂f/∂z = -xeʸsin(z) + 5x²sin(y)eᶻ
J = [eʸcos(z) + 10x sin(y)eᶻ, xeʸcos(z) + 5x²cos(y)eᶻ, -xeʸsin(z) + 5x²sin(y)eᶻ]
J(0, 0, 0) = [1+0, 0+0, 0+0] = [1, 0, 0]

QUIZ
Jacobians and Hessians


1.
Calculate the Jacobian of the function 
f(x, y, z) = x²cos(y) + eᶻsin(y) 
and evaluate at the point 
(x, y, z) = (π, π, 1)

J = [ 2xcos(y)    -x²sin(y) + eᶻcos(y)    eᶻsin(y) ]

J(π, π, 1) = [ 2πcos(π)    -π²sin(π) + ecos(π)    esin(π) ]
           = [ -2π  -e  0 ]


2.
Calculate the Jacobian of the vector valued functions:
u(x, y) = x²y - cos(x)sin(y)
v(x, y) = eˣ⁺ʸ
and evaluate at the point (0, π)

    | ∂u/∂x  ∂u/∂y |   | 2xy + sin(x)sin(y)    x² - cos(x)cos(y) |

          | 0     1  |

3.
Calculate the Hessian for the function
f(x, y) = x³cos(y) − xsin(y)

    ⎾ ∂ₓₓf  ∂ₓᵧf ⏋   ⎾  6xcos(y)               -3x²sin(y) − cos(y) ⏋
H = ⎿ ∂ᵧₓf  ∂ᵧᵧf ⏌ = ⎿ -3x²sin(y) − cos(y)     -x³cos(y) + xsin(y) ⏌



4.
