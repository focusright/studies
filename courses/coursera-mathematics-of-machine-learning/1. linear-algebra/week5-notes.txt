Ax = λx          (A is a matrix, x is a vector, λ is a scalar)
(A - λI)x = 0    (when x = 0 this is a trivial answer, so we want to find when A - λI = 0, to do that we use the determinant)
det(A - λI) = 0

    |a b|
A = |c d|

   ⎾|a b|   |λ 0|⏋
det⎿|c d| - |0 λ|⏌ = 0
   ⎾a-λ  b ⏋
det⎿ c  d-λ⏌ = 0
(a-λ)(d-λ) - bc = 0
ad - aλ - dλ + λ² - bc = 0
λ² - λ(a + d) + ad - bc = 0   (This is called the characteristic polynomial)
